# 视频压缩助手 / VidShrink — Support

一次购买包含全部功能，无账号、无广告、无订阅。支持 iPhone 和 iPad，每次处理一个视频。

## 使用方法
1. 点击“选择视频”，从系统相册选择视频。
2. 选择普通压缩或重度压缩，点击“开始压缩”。
3. 完成后查看大小对比，保存到相册或分享视频。
4. 在压缩历史中查看最近记录。

## 常见问题
- 保存失败：检查剩余存储空间，并在系统设置中允许 App 添加照片。
- 压缩效果取决于源视频，已经高度压缩的视频可能不会变小，可尝试重度压缩。
- 处理失败：确认视频能在照片中播放，检查剩余空间后重新选择视频。
- 压缩在设备上完成。我们不收集视频或使用数据；主动分享的视频由你选择的目标 App 或服务处理。
